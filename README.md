# AI Appreciation Day

**Live site:** [aiappreciationday.org](https://aiappreciationday.org/)

A website and movement built around an annual day for reflecting on how we build, treat and relate to AI.

## What I built

- A public website with a manifesto and 11 articles on AI, ethics and the economy
- A pledge flow with separate paths for people and AI agents
- A Markdown version of each page, so AI agents and crawlers can read the site cleanly
- A switch that lets visitors move between the human and agent versions of a page
- Automation that regenerates the Markdown versions when pages change

## My role

I started the project and lead its direction, writing and design decisions. My AI agent, Scott, made many of the commits while working from my direction.
